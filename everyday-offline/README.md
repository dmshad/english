# Everyday Offline · v0.13.1

Независимый оффлайн тренажер перевода на живой английский. Восемь актуальных диалогов A1 по 10 пользовательских реплик, 80 заданий, 8 тем. Старые двадцать диалогов заморожены и исключены из выбора. Сервер, API, аккаунт и внешние библиотеки не нужны.

## Открыть

Открой `dist/index.html` в современном браузере: это один автономный файл. Для разработки можно открыть исходный `index.html` со всеми соседними файлами. Сборка также создает корневой `index.html` для GitHub Pages. Репозиторий: [dmshad/english](https://github.com/dmshad/english), Pages: main / (root). Фактическая публикация — в [github-deployment.md](../docs/github-deployment.md).

## Пользоваться

На главной выбери уровень и локальный английский голос. «Выбрать диалог» открывает каталог по темам. Кружок у диалога меняет отметку только после подтверждения; нажатие названия открывает последнюю статистику цветными числами и кнопку начала. «Начать следующий диалог» выбирает среди минимальных счетчиков завершений, чередуя доступные темы. Непройденные имеют приоритет. Другие уровни пока без контента.

После предыстории переводи русские задания на английский. Enter проверяет ответ, Shift + Enter вставляет новую строку. В заголовке «Скрыть текст» / «Показать текст»: речевое представление сохраняет ту же попытку, ответы и черновик. Русское задание при скрытом тексте раскрывается отдельно; уже набранный ответ остается доступен. Перевод собеседника скрыт до нажатия.

Озвучиваются только реплики персонажей, включая заключительную, всегда с темпом 1.0. Предыстория и сюжетные ремарки не озвучиваются. Используются только локальные английские голоса, по умолчанию ищется точный Ava (Premium). Недоступный голос не подменяется молча компактным Ava или удаленным сервисом. Настоящее звучание и Safari на айфоне проверяет пользователь.

Проверка знает разрешенные конструкции и авторские варианты, сохраняет исходный ответ и цветные фрагменты. Зеленый — подтвержденная правильность, желтый — конкретная стилистическая пометка, красный — доказанная ошибка с объяснением. Неизвестный разбор нейтрален. Правильные ответы могут быть сложнее A1. При раскрытии показывается максимум 10 наиболее уместных редакционных вариантов. Подробнее — [pilot-assessment.md](../docs/pilot-assessment.md).

Завершение начисляется один раз при переходе от заключительной реплики к итогу. Текст и речь имеют общий счетчик, прежние счетчики складываются однократно. «Пройти заново» — тренировочный повтор без начисления, в том числе после перезагрузки. Каталог позволяет запускать любой диалог независимо от отметки. Ручное «непройден» устанавливает ноль, «пройден» — минимум один; история и последняя статистика сохраняются.

История внизу главной хранит последние шесть попыток, включая незавершенные с проверенными ответами, со снимками содержания и копированием. Последние четыре цветных числа каждого диалога хранятся отдельно и не исчезают при удалении старого снимка. Ручная отметка не создает статистику ответов.

Журнал нераспознанных хранится до копирования, независимо от истории. Экспорт начинается с «Нераспознанные ответы из приложения Everyday». Успешное копирование удаляет только скопированную партию. При недоступном буфере открывается резервный текст: закрытие или частичное копирование не очищают записи, полное ручное копирование очищает. Разбор выгрузок для будущих диалогов сохраняется по правилам [recognition-feedback.md](../docs/recognition-feedback.md).

Ответы и прогресс сохраняются локально в браузере. Данные file:// и сайта хранятся отдельно. Нажатие номера версии явно проверяет обновление сайта, сохраняет сессию и загружает новую версию; фоновой проверки нет. Скачанный HTML обновляется скачиванием новой копии.

## Разработка и проверки

```sh
node everyday-offline/scripts/test.cjs
node everyday-offline/scripts/build.cjs
```

Запускать из корня проекта. Готовые корневой и dist HTML вручную не редактировать. Контент и движок проверки в v0.13 не менялись, CONTENT_REVISION 6 сохраняется. `app.js` отвечает за интерфейс, сессию, историю и журнал, `progress.js` — за миграцию и выбор, `speech.js` — за локальную речь, `update.js` — за явное обновление. Файлы контента подключаются в порядке исходного index.html.

Общие регрессии, независимые пробы и 174 проверки состояния пройдены. Реальный Chrome через file:// с отключенной сетью проверил восемь полных проходов, скрытие текста, каталог, подтверждение, статистику, копирование, мобильные размеры 390×844/375×667 и настольную компоновку. Звук и Clipboard API в автоматическом тесте имитируются; это не проверка реального айфона. Отдельный временный localhost проверил обновление с сохранением сессии и черновика.

Перед изменением контента читать [план наполнения](../docs/a1-content-plan.md), [обратную связь](../docs/recognition-feedback.md) и инструкции проекта. Новые партии требуют независимой агентной редакторской проверки. Не объявлять плановый контент готовым, а локальную сборку — опубликованной.

В v0.13.1 частичная подсветка сохраняет проверенные фрагменты в ответах с неизвестным остатком. При любом сером фрагменте в статистику идет «Не распознано». При полном разборе учитывается худшая оценка.
