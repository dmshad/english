# Обратная связь из журнала нераспознанных ответов

Статус: требование пользователя от 2026-11-24. Это сохраняемые рабочие заметки проекта для будущего наполнения и независимой проверки, а не автоматическое обучение модели.

## Порядок работы

1. Пользователь передает скопированную выгрузку, обычно в отдельном чате. Ее заголовок — «Нераспознанные ответы из приложения Everyday». Разбор для пользователя по умолчанию не нужен.
2. Для каждого примера прочитать контекст, реплику собеседника, русское задание и исходный ответ. Разделить доказанную ошибку, естественный правильный ответ, допустимый по контексту вариант и случай, требующий уточнения. Unknown сам по себе ничего не доказывает.
3. Записать здесь ID/ход, исходный ответ, вывод с причиной и обобщаемое семейство конструкций. Сохранять отрицания, количество и существенный смысл. Не выдавать спорный случай за ошибку.
4. Для правильных нераспознанных вариантов отметить, чего не хватило авторам: краткой формы, синонима, порядка слов, вежливой конструкции или другого естественного речевого действия. Добавить близкие неправильные контрпримеры и требования к цветам/объяснениям. Ошибочные ответы использовать как отрицательные пробы, не как принимаемые формулировки.
5. Перед новой партией авторы и независимые агенты читают накопленные выводы и проверяют применимые семейства в своих заданиях, не копируя исключения глобально. Отмечать, какие выводы применены и чем проверены.
6. Изменение существующего движка/диалога выполнять в согласованном объеме с регрессиями. Выгрузка не дает основания автоматически включать все ее строки в принятые ответы.
