# Everyday Offline · v0.5

Независимая оффлайн версия тренажера разговорного английского. 22 диалога A1: 20 прежних и 2 новых пилотных — в гостях и в библиотеке. Все по 10 твоих реплик, 220 заданий. При просмотре максимум 10 предпочтительных естественных вариантов. Для самой практики не нужны API, аккаунт или интернет.

В блоке «Пилот новой проверки» запусти «Вечер у друга» или «Книга и место у окна». Их движок разбирает конструкции, именные группы и известные ошибки, показывает три цвета и объяснения. Сложность ответа не ограничена A1. Неподдерживаемые конструкции остаются «Не распознано». Остальные 20 диалогов используют прежнюю проверку и явно помечены. Полное описание — в ../docs/pilot-assessment.md.

## Открыть

Открой `dist/index.html` двойным щелчком в современном браузере. Этот один файл можно скопировать на другой компьютер. Либо открой исходный `index.html`, сохранив рядом `styles.css`, `content.js`, `content-stage1.js`, `content-ten.js`, `content-answers.js`, `structured.js`, `content-pilot.js`, `engine.js`, `app.js`.

Репозиторий: https://github.com/dmshad/english. Сборка создает также корневой index.html для GitHub Pages; источник публикации main / (root). Подробности в корневом README.

## Пользоваться

Выбери A1, тему, длину и случайную либо конкретную ситуацию. Переведи русскую реплику. Enter проверяет ответ, Shift + Enter вставляет новую строку. Перевод реплики собеседника и другие варианты скрыты до нажатия. Если не знаешь ответ, можно открыть эталон без оценки.

Сначала предлагаются непройденные диалоги с учетом уровня, темы и длины. Смена случайной темы на конкретную не сбрасывает прохождение. Пройденные доступны для повторения, когда непройденных в выбранном наборе не осталось. Диалог отмечается пройденным после завершения; правильность ответов на отметку не влияет.

В главном меню кнопка «История»: последние 6 разговоров с твоими ответами, результатами, эталонами, вариантами и копированием. Есть и незавершенные разговоры после первой проверки. При появлении седьмого старый удаляется автоматически, но отметка пройденного сохраняется. Повторный проход записывается отдельно.

«Не распознано» означает, что вариант не найден в базе. Внизу страницы — журнал таких ответов, его можно скачать для разбора в чате. Кнопки копирования включают контекст и эталон; если браузер ограничивает доступ к буферу, появляется поле для ручного копирования.

Прогресс и журнал хранятся локально в браузере. Другой браузер, профиль, путь файла или очистка данных могут сделать сохранение недоступным. Для переноса скачивай журнал. При запрете хранилища виден баннер; приложение продолжает работать в памяти до закрытия. Журнал не отправляется в сеть и не меняет проверку автоматически.

В v0.2 изменились длины и сюжеты: сохраненный диалог v0.1 нужно начать заново. При обнаружении старой сессии приложение объясняет это и сохраняет журнал нераспознанных ответов. Последующие сессии v0.2 продолжаются как обычно.

v0.3 сохраняет текущую сессию v0.2 и переносит ее в историю, если есть проверенные ответы. Старый список открытых диалогов не считается списком пройденных. Других старых разговоров в данных v0.2 нет: задним числом они не появятся.

## Разработка и контент

Сначала читай `../AGENTS.md`, `../docs/offline-spec.md`, `../docs/decisions.md`.

- `content.js` — написанные вручную диалоги, эталоны, естественные и допустимые варианты.
- `content-stage1.js` — 14 новых диалогов первого этапа; использует helper из content.js.
- `content-ten.js` — индивидуальные продолжения 16 сценариев до 10 ходов, ревизия контента 3.
- `content-answers.js` — дополнительные авторские формулировки; после загрузки всех данных удаляет дубли оформления. Подключать после engine.js и основных файлов контента.
- `structured.js` — ограниченная грамматика пилота, диагностика и объяснения. Подключается перед content-pilot.js и app.js.
- `content-pilot.js` — два новых сюжета, по каждому заданию параметры намерения и смысловые ограничения. Старые задания не переводились на новый движок автоматически.
- `engine.js` — нормализация и ограниченные грамматические правила.
- `app.js` — интерфейс, локальное сохранение, журнал и копирование.
- `styles.css` — оформление; без внешних шрифтов.

В v0.4 старая текущая сессия перезапускается из-за нового порядка реплик, но история и журнал остаются. Только дописанные 16 сценариев отмечаются непройденными заново. В меню есть кнопка повторной загрузки опубликованной версии: она сохраняет состояние, не добавляет фоновых запросов и работает только для HTTP(S). При file:// нужно скачать новый файл. Публикация main должна завершиться до обновления страницы на телефоне.

После изменений:

```sh
node everyday-offline/scripts/test.cjs
node everyday-offline/scripts/build.cjs
```

Запускать из корня English. Node нужен только разработчику для проверки и сборки. После изменения исходников пересобирай обе готовые страницы: корневой index.html и everyday-offline/dist/index.html.

Проверки охватывают варианты ответов, сохранение смысла, выбор без повторов и переходы приложения с имитацией DOM. Сборка проверяет синтаксис встроенных скриптов и отсутствие подключаемых файлов. Встроенный браузер Codex запретил `file://`, поэтому визуальная проверка и фактическое открытие локального файла в браузере пока не выполнены. Это необходимо проверить обычным открытием готового файла.

## Ограничения теста

Есть только A1 и три темы. A2–C2 отображаются без возможности запустить отсутствующий контент. Проверка по известным ответам не заменяет оценку преподавателя; свободные перефразировки и опечатки могут не распознаваться. Уровень контента — авторская редакционная оценка, без внешней CEFR-сертификации. Аудио пока нет. Следующие этапы по плану пользователя: перенос на GitHub, затем интерфейс и тщательное испытание.
