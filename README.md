# Everyday — оффлайн английский

Тренажер живого английского в заранее написанных диалогах. Приложение дает реплику на русском; ты переводишь ее на английский и сравниваешь с естественными вариантами для ситуации.

Текущая сборка: **v0.13 — 8 актуальных диалогов A1 по 10 твоих реплик, 8 тем, 80 заданий**. Статус публикации — в docs/github-deployment.md.

## Открыть приложение

- В браузере после включения GitHub Pages: [dmshad.github.io/english](https://dmshad.github.io/english/).
- Без интернета: скачай [готовый index.html](https://github.com/dmshad/english/raw/refs/heads/main/index.html) и открой его в современном браузере. Это один автономный файл.

Нет API, аккаунта, сервера приложения, сетевых запросов или внешних библиотек. Открытие сайта по ссылке требует интернета для загрузки страницы. Скачанный HTML работает оффлайн.

## Что есть

- В гостях, библиотека, обувь, соседи, встреча в парке, автобус, отель и подготовка мероприятия. A2–C2 пока без диалогов.
- Восемь актуальных разговоров с проверкой конструкций, артиклей и известных ошибок; старые двадцать заморожены и скрыты.
- 10 пользовательских реплик в каждом диалоге A1.
- Проверка по расширенному набору формулировок; при просмотре максимум 10 авторских предпочтительных вариантов.
- Скрытые переводы, эталоны, другие варианты и копирование для разбора.
- Сначала непройденные ситуации; история последних шести разговоров.
- Локальный журнал нераспознанных ответов с выгрузкой. Неизвестный ответ не объявляется ошибкой.
- В пилоте: зеленый — верно, желтый — отмеченная формулировка по контексту, красный — установленная ошибка с объяснением. Не распознано сохраняется отдельно. См. [покрытие и ограничения пилота](docs/pilot-assessment.md).

Ответы, история и прогресс сохраняются только в браузере и не отправляются на GitHub. Данные локального файла и сайта по ссылке хранятся отдельно; автоматического переноса между ними нет.

## Обновление на телефоне

После публикации изменений в main и завершения GitHub Pages перезагрузи страницу. Нажатие номера версии проверяет наличие новой версии сайта, сохраняет состояние и открывает обновление с новым параметром URL. В шапке видно номер версии. Переустановка ярлыка на главном экране не нужна. Скачанный HTML сам не обновляется — скачай новый файл. Простая локальная сборка еще не меняет опубликованный сайт.

## Разработка

Исходники — `everyday-offline/`, готовые страницы — корневой `index.html` и `everyday-offline/dist/index.html`. Не редактируй готовые страницы вручную.

```sh
node everyday-offline/scripts/test.cjs
node everyday-offline/scripts/build.cjs
```

Сборка обновляет обе готовые страницы. Node нужен разработчику; пользователю устанавливать ничего не нужно. После изменения исходников проверь и пересобери приложение, затем отправь изменения в main.

## GitHub Pages

В репозитории открой **Settings → Pages → Build and deployment**:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
- **Save**

GitHub публикует готовый корневой HTML. Файл `.nojekyll` отключает ненужную обработку Jekyll. Следующие изменения main публикуются тем же способом.

Ситуации и варианты написаны вручную. Проверка по базе может не узнать правильную формулировку; CEFR-разметка является авторской редакционной оценкой. Реплики озвучиваются локальным английским голосом устройства.

Сюжет у друга ранее переписан после пользовательского теста; новая проверка показывает цветные фрагменты исходной реплики. Серый означает отсутствие уверенного разбора, пропуск слова показан вставкой.

В v0.8 библиотечный разговор переработан: выбор первой книги, оформление билета, тихое место для чтения. content-library.js загружается после content-friend.js. Lets в конструкции «давай» принимается с заметкой о стандартном let’s без штрафа. История сохраняется; обновленный библиотечный сценарий становится непройденным.

Ранее два пустых задания библиотеки заменены содержательными просьбами о ручке и продлении книги. Добавлены варианты порядка слов в вопросе о тихом месте. Правила редакторской проверки — в docs/a1-content-plan.md (от корня), отчет — docs/pilot-assessment.md.

В v0.10 на главной отдельно доступны шесть новых разговоров: обувь, соседский кот, парк, автобус, отель, подготовка встречи. Два предыдущих сохранены ниже. Независимая проверка и принятые замечания — в docs/batch-02-independent-review.md от корня проекта. Автоматические проверки включают авторские и независимые пробы; готовый файл испытан через file:// в Chrome с отключенной сетью.

В v0.11 интерфейс переделан под айфон: светлая/темная темы, отдельные экраны, три фиксированных поля, просмотр предыдущих заданий, итог и история с копированием журнала. В речевом режиме текст и русское задание открываются отдельно; используются только локальные английские голоса устройства, пять скоростей. Прохождения считаются отдельно для текста и речи, повторы выбираются по минимальному счетчику. Старые отметки перенесены в текстовый режим, история и журнал сохранены.

Новый интерфейс проверен в Chrome file:// без сети на 390×844, 375×667 и настольной ширине. Звук автоматический тест имитирует; голос и клавиатуру реального айфона нужно проверить на устройстве. Для обновления страницы после публикации перезагрузи ее; автономный файл заменяется новым index.html. Постоянный порядок наполнения с независимой агентной проверкой — в docs/a1-content-plan.md от корня.

В v0.11.1 тренировочный повтор через «Пройти заново» не увеличивает счетчик завершений. История повторов сохраняется отдельно; обычный запуск с главной учитывается при завершении.

В v0.12 история расположена внизу главной; ремарки и заключительная реплика идут отдельными экранами. Пять скоростей 0.6–1.4, средняя 1.0. По умолчанию ищется локальный Ava (Premium), в режиме речи доступен выбор голоса. Если Safari не предоставляет выбранный голос, он не заменяется молча другим. Настоящее звучание проверяется на устройстве.

В v0.12.1 нажатие на номер версии проверяет обновление сайта и загружает новую сборку с сохранением прогресса. Скачанный HTML обновляется скачиванием нового файла. Самостоятельных фоновых проверок нет.


В v0.13 текст и речь объединены: «Скрыть текст» / «Показать текст» в заголовке сохраняют одну попытку и общий прогресс. Скорость всегда 1.0. Предыстория и ремарки не озвучиваются. Главная содержит постоянный выбор голоса, каталог и следующий диалог; следующие выбираются по минимальному счетчику с чередованием тем. В каталоге ручные отметки меняются только после подтверждения, последняя статистика хранится независимо от шести разговоров истории. Прежние счетчики текст/речь складываются без сброса сессии. Журнал нераспознанных очищается только после копирования, экспорт содержит заголовок и контекст. Содержание восьми диалогов и проверка не менялись. Более ранние описания отдельных режимов и пяти скоростей выше — история прежних версий. Фактическая публикация отмечается в docs/github-deployment.md от корня проекта.
